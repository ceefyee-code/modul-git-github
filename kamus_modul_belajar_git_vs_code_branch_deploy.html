Bab 01 • Fondasi Utama

Kamus Dasar & Bahasa Visual VS Code

Sebelum ngetik perintah apapun, kenalan dulu sama istilah-istilah wajib biar nggak gagal paham pas baca tutorial atau error.

🕰️

Apa itu Git?

Git adalah "Mesin Waktu" di dalam laptopmu. Dia mencatat setiap perubahan kode yang kamu simpan. Kalau kodenya tiba-tiba rusak, kamu bisa balik ke versi kemarin yang masih aman. Git bekerja offline di laptop.

☁️

Apa itu GitHub?

GitHub adalah "Google Drive-nya Programmer" di internet (cloud). Tempat menyimpan hasil catatan Git tadi secara online supaya nggak hilang kalau laptop rusak, bisa pamer portofolio, dan kerja bareng tim.

📖 Kamus Istilah Wajib (Pakai Analogi Sehari-hari)

🎨 Kamus Huruf & Warna File di VS Code

Pernah lihat nama file di Explorer VS Code tiba-tiba berubah warna jadi hijau atau kuning dan ada huruf kecil di kanannya? Ini artinya:

U
Untracked (Hijau)

File baru banget dibuat dan belum pernah dicatat/dilacak oleh Git sama sekali.

M
Modified (Kuning)

File lama yang sudah ada di Git, tapi barusan kamu edit/ubah isinya.

A
Added (Hijau)

File baru yang sudah masuk ke Staging Area (git add) dan siap di-commit.

D
Deleted (Merah)

File yang tercatat di Git tapi baru saja kamu hapus dari folder proyek.

C
Conflict (Merah)

Ada bentrokan kode di baris yang sama saat menggabungkan branch atau melakukan pull. Harus dipilih dulu mana kode yang mau dipakai.

⚡ Shortcut Wajib di VS Code

• Buka/Tutup Terminal VS Code: tekan Ctrl + ~ (Windows) atau Cmd + J (Mac).
• Buka Panel Git (Source Control): klik ikon cabang bercabang 3 di sidebar kiri paling luar atau tekan Ctrl + Shift + G.

Bab 02 • Praktik Pertama

Step-by-Step Upload Proyek Baru dari Nol

Ikuti 8 langkah ini secara berurutan di Terminal VS Code untuk mengirim folder proyek pertamamu ke GitHub. Centang kotak di sebelah kiri setiap langkah yang sudah kamu jalankan!

🚑

Kotak P3K: Solusi Error yang Sering Dialami Pemula

fatal: not a git repository

Penyebab: Kamu lupa ketik git init di awal, atau terminalmu salah folder.
Solusi: Jalankan git init dulu sebelum perintah Git lainnya.

Author identity unknown

Penyebab: Git belum kenal siapa pembuat commit-nya.
Solusi: Jalankan ulang Langkah 1 (git config --global user.name & user.email).

error: remote origin already exists

Penyebab: Link origin sudah pernah dimasukkan sebelumnya.
Solusi: Hapus link lama dengan git remote remove origin lalu masukkan ulang link yang benar.

Diminta Password / Authentication Failed

Penyebab: GitHub tidak lagi menerima password akun biasa di terminal.
Solusi: Login lewat jendela pop-up browser VS Code, atau buat Personal Access Token (PAT) di GitHub (Settings → Developer settings → Tokens classic) lalu tempel token itu sebagai pengganti password.

🖱️ Cara B: Klik Tombol di UI VS Code (Tanpa Ketik)
  1. Klik ikon Source Control (ikon cabang di sidebar kiri VS Code, ada angka biru jumlah file berubah).
  2. Arahkan kursor ke tulisan Changes, lalu klik ikon + (Stage All Changes).
  3. Ketik pesan perubahan di kotak Message (misal: fix warna tombol).
  4. Klik tombol biru Commit.
  5. Tombol biru berubah jadi Sync Changes → klik tombol itu untuk langsung push ke GitHub!

2 Skenario 2: Mengambil Update Terbaru dari GitHub (pull vs fetch)

Kalau teman satu tim baru upload kode baru ke GitHub (atau kamu edit file langsung di web GitHub), kamu harus menyedot perubahan itu ke laptopmu sebelum mulai ngoding lagi.

⬇️ git pull (Langsung Sedot & Gabung)

Mengunduh perubahan terbaru dari GitHub sekaligus langsung menggabungkannya ke file di VS Code kamu. Paling sering dipakai sebelum mulai kerja.

👀 git fetch (Intip Dulu Tanpa Mengubah File)

Hanya mengecek dan mengunduh info update dari GitHub ke memori Git tanpa menyentuh file yang sedang kamu edit. Aman kalau kamu mau cek ada update apa saja dulu.

3 Skenario 3: Unduh Proyek ke Laptop Baru (Clone)

Ganti laptop atau mau unduh repo GitHub ke folder lokal? Jangan download ZIP! Pakai git clone supaya riwayat Git dan link origin otomatis terhubung.

💡 Tips VS Code: Buka jendela baru VS Code → klik tulisan biru Clone Git Repository... di layar Welcome → tempel URL GitHub.

Bab 04 • Fitur Super Git

Kupas Tuntas Materi Branch (Cabang Kerja)

Bayangkan kamu punya website yang sudah jalan bagus di cabang main. Lalu kamu mau bikin fitur baru yang berisiko bikin error. Nah, di sinilah Branch menyelamatkan hidupmu!

🌿

Analogi "Dunia Paralel" (Salinan Draf Aman)

Branch adalah salinan jalur kerja paralel dari kodemu. Saat kamu bikin branch baru bernama fitur-login, kamu bebas mengacak-acak kode di cabang itu. Cabang utama (main) tetap bersih dan aman. Kalau fitur barunya sudah jadi dan sukses, tinggal digabungkan (Merge) ke main!

Visualisasi Pohon Commit & Posisi HEAD

Status Saat Ini: git status (On branch main)

Kamu sedang berada di cabang main (ditandai lencana kuning HEAD di commit C2). Klik tombol "1. Buat Branch Fitur" untuk mulai bercabang!

7. Gimana Kalau Terjadi Merge Conflict di VS Code? (Jangan Panik!)

Conflict terjadi kalau dua cabang mengedit baris kode yang persis sama. VS Code akan otomatis memunculkan 4 tombol ajaib di atas baris yang bentrok:

  • Accept Current Change → Pakai kode milikmu yang sekarang (HEAD).
  • Accept Incoming Change → Pakai kode baru yang masuk dari cabang lawan.
  • Accept Both Changes → Simpan kedua-duanya (atas dan bawah).

Setelah klik salah satu tombol di atas, tinggal git add . → git commit -m "resolve conflict" → git push!

Bab 06 • Onlinekan Karyamu

Step-by-Step Publish & Deploy Website Gratis

Kodenya sudah rapi di GitHub? Saatnya bikin website-mu punya link publik yang bisa dibuka lewat HP siapa saja secara gratis!

🐙 Kapan Pilih GitHub Pages?

Web Statis

Cocok kalau proyekmu berisi HTML, CSS, dan JavaScript murni (tanpa proses build Node.js). Langsung aktif dari dalam pengaturan repositori GitHub tanpa perlu daftar akun lain. Link berbentuk: username.github.io/nama-repo.

▲ Kapan Pilih Vercel?

Super Cepat & Modern

Cocok untuk HTML statis maupun framework modern (React, Next.js, Vite, Vue, Tailwind CLI). Punya fitur Preview Link otomatis setiap kali kamu push branch baru! Link berbentuk: nama-proyek.vercel.app.

🚀 Panduan A: Deploy ke GitHub Pages

Syarat Wajib: Di folder utama (root) repositori GitHub-mu harus ada file bernama index.html (huruf kecil semua).
